# Photogenesis

Песочница, в которой свет рождает материю.

**Играть:** https://shirokovst.github.io/photogenesis/

Ставь источники света, призмы и зеркала. Там, где скрещиваются лучи разных источников, появляется вещество, а вещество меняет путь света, и мир перестраивается сам.

| Свет | Что происходит |
|---|---|
| красный + синий | рождается кристалл: растёт вдоль лучей и преломляет свет |
| красный + зелёный | рождается пыль: падает и поглощает свет |
| зелёный + синий | растворяет кристалл |
| белый | сжигает пыль |

Интерфейс на английском (по умолчанию) и русском, переключатель EN / RU есть в панели и на стартовом экране. Тексты лежат в `src/ui/strings.ts`.

## Запуск

Нужен [Node.js](https://nodejs.org/) 20+.

```bash
npm install
npm run dev
```

Игра откроется на `http://localhost:5173`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | dev-сервер с горячей перезагрузкой |
| `npm run build` | проверка типов и сборка в `dist/` для хостинга |
| `npm run build:single` | вся игра в одном файле `dist-single/index.html`, открывается двойным кликом |
| `npm run preview` | локально раздаёт собранный `dist/` |
| `npm test` | тесты |

## Публикация

При каждом пуше в `main` GitHub Actions прогоняет тесты, собирает игру и выкладывает её на GitHub Pages (`.github/workflows/deploy.yml`).

## Устройство

```
src/
├── main.ts        игровой цикл
├── sim/           симуляция: сетка, свет, реакции, физика (без DOM и Canvas)
├── render/        отрисовка мира на canvas
├── input/         инструменты мыши
├── ui/            панель, легенда, стартовый экран, тексты интерфейса
└── assets/        логотип
tests/             тесты симуляции
```

Каждый тик: реакции, затем физика пыли, затем трассировка лучей. Цвет света хранится как битовая маска (красный `001`, зелёный `010`, синий `100`), поэтому смешение лучей сводится к побитовому ИЛИ.
